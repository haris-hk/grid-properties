APNA GHAR PROGRAM — BILINGUAL DEVELOPER PACKAGE

This package is ready for desktop, tablet and mobile.
It now includes English + Urdu with a working language switcher.

FILES
- index.html
- styles.css
- script.js
- assets/

HOW TO USE
1. Upload the full folder to your hosting/server.
2. Open index.html.
3. English is the default language.
4. Click “اردو” in the header to switch the full page to Urdu.
5. Urdu automatically switches the whole UI to RTL (right-to-left).
6. The selected language is saved in the visitor's browser using localStorage.

FORM
The form is front-end ready and validates required fields.
In script.js, replace the console.log lead handler with your CRM/API endpoint.

URDU FONT
The CSS uses this fallback stack:
Noto Nastaliq Urdu, Noto Sans Arabic, Segoe UI, Tahoma, Arial.
If your production site already loads Noto Nastaliq Urdu or Noto Sans Arabic, the Urdu page will use it automatically.
